# 주식회사 루카스엔터테인먼트 — 공식 홈페이지

LUKAS ENTERTAINMENT 공식 홈페이지 정적 사이트입니다. 빌드 도구 없이 HTML/CSS/JS만으로 동작하며, GitHub Pages에서 그대로 서비스됩니다.

- 공개 주소: https://lukas6525.github.io/lukasent-web/
- 구조
  - `index.html` — ABOUT / BUSINESS / CREATOR / PRODUCTION / PORTFOLIO / CONTACT
  - `styles.css` — 디자인 시스템·레이아웃·반응형
  - `script.js` — KR/EN 전환, 메뉴, 스크롤 애니메이션, 필터, 폼 검증, 약관 모달
  - `assets/` — 이미지, 폰트(Pretendard·Anton·Playfair Display), favicon
  - `robots.txt`, `sitemap.xml`
- 수정 후 `main` 브랜치에 커밋·푸시하면 1~2분 안에 자동 반영됩니다. (`.nojekyll`로 Jekyll 처리를 끈 순수 정적 배포)
